# Droplet Biosciences

> Cambridge, Massachusetts clinical-stage molecular diagnostics company (founded 2021, backed by The
> Engine Ventures) that pioneered a lymph liquid biopsy platform. Droplet stabilizes and extracts
> lymphatic fluid from routine post-surgical drain material, where circulating tumor DNA is present at
> substantially higher levels than in matched plasma, and runs tumor-informed ctDNA assays on it to
> detect molecular residual disease after cancer surgery. Its lead test, LymphDetect, targets
> HPV-independent head and neck squamous cell carcinoma and is run in the company's own CLIA-licensed
> laboratory.

## What Droplet Biosciences offers developers

Nothing, deliberately. Droplet is a laboratory and assay company, not a software vendor. There is no
developer program, no developer portal, no documentation, no SDK, no support channel for developers, no
pricing and no signup. The subdomains api., developer., developers., docs., portal., app., trust. and
status..dropletbiosci.com do not resolve. No OpenAPI, GraphQL or AsyncAPI description is published
anywhere, and every RFC 8615 /.well-known/ path on the host returns 404 — including agent-card.json,
so there is no A2A agent card.

## Machine-readable surfaces that DO exist, and what they actually are

The company's marketing site is WordPress, and that WordPress installation exposes live, callable
endpoints. They are real, but none of them is a Droplet product interface — read this section before
treating Droplet as an API provider.

- WordPress core REST API: https://dropletbiosci.com/wp-json/ — 472 routes across 19 namespaces, served
  anonymously. Content collections under wp/v2 are readable without a credential, including the custom
  types `publications`, `press-releases` and `team`. Page-number pagination (`page`, `per_page`) with
  `X-WP-Total` and `X-WP-TotalPages` response headers. Undocumented, unversioned beyond the wp/v2
  namespace, no rate-limit headers, no idempotency, `x-robots-tag: noindex`.
- Model Context Protocol endpoints: three servers advertised at https://dropletbiosci.com/wp-json/mcp —
  `mcp-adapter-default-server`, `events-manager`, `amelia-mcp-server`. All three answer JSON-RPC but
  return HTTP 401 `rest_forbidden` to `tools/list`, so no tool list or input schema is publicly
  observable. They come from the WordPress MCP Adapter and two booking/events plugins; their subject
  matter is site events and bookings, not diagnostics.
- OAuth 2.0 authorization server: metadata at https://dropletbiosci.com/wp-json/oauth/v1/metadata.
  authorization_code + refresh_token, PKCE S256 required, open RFC 7591 dynamic client registration,
  public clients only, one scope (`events-manager:mcp`). It is NOT served at the RFC 8414 well-known
  path, its JWKS is served but empty, and the 401 challenge carries no WWW-Authenticate pointer, so
  standards-compliant discovery fails.

An agent should treat this profile as company reference information. There is no Droplet API to call to
order a test, retrieve a result, or query the assay.
